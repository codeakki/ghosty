```ts
import OpenAI from 'openai';

const zg = new OpenAI({
  baseURL: process.env.ZG_ROUTER_URL,   // e.g. https://router-api-testnet.integratenetwork.work/v1
  apiKey: process.env.ZG_API_KEY,
});

const res = await zg.chat.completions.create({
  model: process.env.ZG_MODEL!,          // pick from pc.0g.ai/models
  messages: [
    { role: 'system', content: 'You are Ghosty. Return JSON {action, plan, reason}.' },
    { role: 'user', content: JSON.stringify({ event, memory }) },

const requestId = res.id;               // log this per decision (see Unverified)
```

## Storage

Package **`@0gfoundation/0g-storage-ts-sdk`** (peer dep `ethers`). Not `@0glabs/0g-ts-sdk`. Docs: https://docs.0g.ai/developer-hub/building-on-0g/storage/sdk

```ts
import { ZgFile, Indexer } from '@0gfoundation/0g-storage-ts-sdk';
import { ethers } from 'ethers';

const RPC = 'https://evmrpc-testnet.0g.ai';
const signer = new ethers.Wallet(PK, new ethers.JsonRpcProvider(RPC));
const indexer = new Indexer('https://indexer-storage-testnet-turbo.0g.ai');

const file = await ZgFile.fromFilePath('./mem.json');
await file.merkleTree();
const [tx, err] = await indexer.upload(file, RPC, signer);
await file.close();

await indexer.download(rootHash, './out.json', true);   // true = verify proof
```

### Encryption (SDK v1.2.6+)

- Upload option `encryption: { type: 'aes256', key }` or `{ type: 'ecies', recipientPubKey }`.
- Decrypt via `indexer.downloadToBlob()`.
- **A wrong key silently returns ciphertext.** Test a decrypt round trip on server boot and fail loudly.

## How Ghosty uses 0G

| Need | 0G piece | Record |
|---|---|---|
| Decide on an event or answer a question | Compute (Router or broker) | Request ID |
| User memory (prefs, risk limits, history) | Storage, AES-256 | Root hash of latest memory blob |
| Episode log (one per decision) | Storage, AES-256 | `{ts, input, requestId, output, action, fills}` → root hash |
| Safe-stop | Health probe on Compute + Storage | `/health.safeStop` |

Episode record shape (suggested):

```json
{
  "ts": "2026-11-07T10:15:00Z",
  "trigger": "news|voice",
  "input": { "headline": "...", "ethos": 1800 },
  "requestId": "chatcmpl-...",
  "model": "...",
  "decision": { "action": "alert", "plan": [{ "venue": "hyperliquid", "coin": "xyz:GOLD", "side": "buy" }] },
  "user": "confirm",
  "fills": [{ "oid": 123 }],
  "prevRoot": "0x..."
}
```

`prevRoot` chains episodes so a judge can walk the history from the latest root.

## Implementation notes

Written 2026-11-06 while building `feat/server-0g`. Checked against docs.0g.ai, the npm registry, the live mainnet Router and Galileo testnet. Code: `server/src/agent/`, `server/src/safety/safeStop.ts`.

### Packages (server/package.json)

| Package | Version | Why |
|---|---|---|
| `openai` | `^7.52.0` | Router client (`baseURL` + `apiKey`). |
| `@0gfoundation/0g-storage-ts-sdk` | `^1.2.13` | Storage upload/download. Peer dep is **exactly** `ethers@6.13.1`. |
| `ethers` | `6.13.1` (pinned, saved as `^6.13.1`) | Signer for storage txs. A newer 6.x fails npm peer resolution. |

The SDK's `.d.ts` resolves ethers' CJS typings while we load the ESM build, so `Wallet` is cast to the SDK's `Signer` type in `storage.ts`. Same class at runtime.

### Differences from the earlier research

- **Router request id.** The response body has `x_0g_trace: { request_id, provider, billing }` (docs: Chat Completions page). The Router also sends **two** `X-Request-Id` headers (gateway id, then router id). `fetch` joins them as `"<gateway>, <router>"`. Error bodies carry a top-level `request_id` equal to the second header value (checked with a bad key against `router-api.0g.ai`: 401, `invalid_api_key`).
- **`GET /v1/models` needs no auth** (docs: Models page; checked live on mainnet). Each entry lists `supported_parameters`.
- **Model ids.** The docs use `glm-5.2` as an example, but the live mainnet catalog (2026-11-05) has no `glm-5.2`. It lists `glm-4.5`, `glm-4.7`, `glm-5`, `glm-5.3-flash`, `gpt-5-mini`, `gemini-3.5-flash`, `deepseek-v4-flash`, `qwen3.x-flash` and others. Default `OG_MODEL=glm-4.7`, which lists `response_format`.
- **SDK encryption is AES-256-CTR, no auth tag** (`common/encryption.js` uses `@noble/ciphers` `ctr`). A wrong key returns ciphertext without an error. We encrypt memory ourselves with **AES-256-GCM** (`agent/crypto.ts`) and upload the ciphertext as a normal file. A wrong key or a tampered blob then throws.
- **Upload return shape:** `[{ txHash, rootHash, txSeq } | { txHashes, rootHashes, txSeqs }, Error | null]`. Files of 4 GB or less use the first form.
- **Router errors** (docs: Errors page): 400, 401, 402 `insufficient_balance`, 403, 404, 429 (honour `Retry-After`), 502 `provider_error`, 503 `no_available_provider`. The Router never falls back to another LLM.
- **Router billing** is a single on-chain balance in the 0G Payment Layer (testnet contract `0x0AD9690e0b34aB2d493DE02cDF149ee34f6C9939`, mainnet `0xA3b15Bd2aD18BFB6b5f92D8AA9F444Dd59d1cE32`). It is separate from Direct sub-accounts. The docs give no minimum deposit.

### How request ids are captured (`ZeroGDecider`)

1. `client.chat.completions.create(...).withResponse()` returns `{ data, response, request_id }`.
2. `Decision.requestId` is `data.x_0g_trace.request_id`. If that is missing, it falls back to the last `x-request-id` value, then to `data.id`.
3. `Decision.zeroG = { completionId, traceRequestId, headerRequestId (raw), model, provider, attempts }`.
4. Every response logs one line, `0G compute response`, with all of the ids above. On failure, `BrainOfflineError.requestId` comes from the router `x-request-id`.
5. The id travels into the episode blob (`requestId`, `decision.zeroG`), the local index and the user's memory history.

Decision contract: the model must return `{signal, confidence, rationale, suggestedActions[{venue, market, side, sizePct}]}`. It is parsed with zod after stripping `<think>` blocks and code fences, with one retry and a corrective message. Legs are kept only for `hyperliquid` and only on watchlist markets, then scaled to `MAX_TRADE_USD x risk multiplier`. The 20 s deadline covers both attempts, and the OpenAI SDK's own retries are off (`maxRetries: 0`). Any error throws `BrainOfflineError` and marks the brain offline for the safe-stop cache window. There is no fallback to `FakeDecider`.

### Storage layout

- **Memory:** `encrypt_gcm({v:1, kind:"ghosty.memory", userId, savedAt, memory})` is written to a temp file and goes through `ZgFile.fromFilePath`, `merkleTree()` and `indexer.upload(file, RPC, signer)`. Pointers live in `server/.ghosty/memory.json` as `{users: {<id>: {rootHash, txHash, savedAt}}}`. The key is `OG_MEMORY_KEY` (64 hex chars), or `sha256("ghosty:memory:v1:" + OG_PRIVATE_KEY)`.
- **Episodes:** each blob is plaintext JSON `{v, kind:"ghosty.episode", seq, ts, requestId, newsIds, decision{signal, confidence, rationale, zeroG}, actions, orders, outcome, prevRoot}`. `prevRoot` chains episodes, so you can walk back from the newest root. With `OG_EPISODE_BATCH=true` one blob holds `{kind:"ghosty.episode-batch", prevRoot, episodes:[...]}`. The index is `server/.ghosty/episodes.jsonl`, one line `{ts, seq, requestId, outcome, rootHash, txHash, sha256, batchSize}` per episode.
- Uploads run in the background through one serial queue: one signer means no nonce races. `flush()` waits for the queue. A failed episode upload goes back into the buffer and is retried with the next upload.
- `server/.ghosty/` writes its own `.gitignore` (`*`), so pointers are never committed.

### Gas and faucet

Measured with an unfunded wallet against Galileo (2026-11-06). The SDK got as far as `eth_estimateGas`:

- Storage fee for a 23-byte, 1-segment file: **30,733,644,962 wei = 3.1e-8 0G**, sent as `value`. It scales per 256 KiB segment, and episodes and memory are well under one segment.
- Gas price: about **4 gwei** (`0xee6b2807`). Gas units were not measured because the estimate failed for lack of funds. Assuming 150k–300k gas, each upload costs about 0.0006–0.0012 0G, so the **0.1 0G/day faucet covers roughly 80–160 uploads**.
- Per button cycle without batching: 2 episode uploads (proposed + executed/cancelled) + 1 memory upload = 3 txs. With `OG_EPISODE_BATCH=true` and `OG_EPISODE_BATCH_SIZE=5`, that drops to about 1.4 txs per cycle.
- Router compute is paid from the Router deposit, not from this wallet.

### Verify an episode by hand

1. Take a line from `server/.ghosty/episodes.jsonl`.
2. Open `https://chainscan-galileo.0g.ai/tx/<txHash>`. It should be a call to the flow contract `0x22e0...5296` from the `OG_PRIVATE_KEY` address.
3. Open `https://storagescan-galileo.0g.ai` and search for the `rootHash` (or the `txHash`). The file size should match, with status finalized. We have not tried this search yet.
4. Download it and check the contents: `ZeroGEpisodeLog.verify(rootHash)` downloads with merkle proofs, compares sha256 with the index, and checks the request ids. With the bare SDK: `await new Indexer(INDEXER).download(rootHash, "./ep.json", true)`, then read `requestId` and match it against the server log line `0G compute response`.
