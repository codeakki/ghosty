## Compute

### Option A: Router (OpenAI-compatible, easiest)

| Network | Base URL | API keys |
|---|---|---|
| Mainnet | `https://router-api.0g.ai/v1` | https://pc.0g.ai |
| Testnet | `https://router-api-testnet.integratenetwork.work/v1` | pc.testnet.0g.ai |

Model list: https://pc.0g.ai/models

```ts
import OpenAI from 'openai';

const zg = new OpenAI({
  baseURL: process.env.ZG_ROUTER_URL,   // e.g. https://router-api-testnet.integratenetwork.work/v1
  apiKey: process.env.ZG_API_KEY,
});

const res = await zg.chat.completions.create({
  model: process.env.ZG_MODEL!,          // pick from pc.0g.ai/models
  messages: [
    { role: 'system', content: 'You are Ghosty. Return JSON {action, plan, reason}.' },
    { role: 'user', content: JSON.stringify({ event, memory }) },
  ],
});
const requestId = res.id;               // log this per decision (see Unverified)
```

### Option B: direct broker SDK (TEE, signed responses)

Package `@0gfoundation/0g-compute-ts-sdk` (Node 20+). Flow:

```
createZGComputeNetworkBroker(wallet)
  → broker.ledger.depositFund(...)        // needs 3 0G
  → listService()
  → transferFund(...)                     // to the chosen provider
  → getServiceMetadata(provider)          // endpoint + model
  → getRequestHeaders(provider, content)  // signed billing headers
  → POST <endpoint>/chat/completions
```

Use B only if we get enough testnet 0G; the TEE signature is a nice judging point.

## Storage

Package **`@0gfoundation/0g-storage-ts-sdk`** (peer dep `ethers`). Not `@0glabs/0g-ts-sdk`. Docs: https://docs.0g.ai/developer-hub/building-on-0g/storage/sdk

```ts
import { ZgFile, Indexer } from '@0gfoundation/0g-storage-ts-sdk';
import { ethers } from 'ethers';

const RPC = 'https://evmrpc-testnet.0g.ai';
const signer = new ethers.Wallet(PK, new ethers.JsonRpcProvider(RPC));
const indexer = new Indexer('https://indexer-storage-testnet-turbo.0g.ai');

const file = await ZgFile.fromFilePath('./mem.json');
await file.merkleTree();
const [tx, err] = await indexer.upload(file, RPC, signer);
await file.close();

await indexer.download(rootHash, './out.json', true);   // true = verify proof
```

### Encryption (SDK v1.2.6+)

- Upload option `encryption: { type: 'aes256', key }` or `{ type: 'ecies', recipientPubKey }`.
- Decrypt via `indexer.downloadToBlob()`.
- **A wrong key silently returns ciphertext.** Test a decrypt round trip on server boot and fail loudly.

### KV store

`Batcher` to write, `KvClient.getValue(streamId, base64Key)` to read. Import paths UNVERIFIED. For the hackathon, an append-only list of episode files plus a small "index" file (latest root hashes) is enough.

## How Ghosty uses 0G

| Need | 0G piece | Record |
|---|---|---|
| Decide on an event or answer a question | Compute (Router or broker) | Request ID |
| User memory (prefs, risk limits, history) | Storage, AES-256 | Root hash of latest memory blob |
| Episode log (one per decision) | Storage, AES-256 | `{ts, input, requestId, output, action, fills}` → root hash |
| Safe-stop | Health probe on Compute + Storage | `/health.safeStop` |

Episode record shape (suggested):

```json
{
  "ts": "2026-11-07T10:15:00Z",
  "trigger": "news|voice",
  "input": { "headline": "...", "ethos": 1800 },
  "requestId": "chatcmpl-...",
  "model": "...",
  "decision": { "action": "alert", "plan": [{ "venue": "hyperliquid", "coin": "xyz:GOLD", "side": "buy" }] },
  "user": "confirm",
  "fills": [{ "oid": 123 }],
  "prevRoot": "0x..."
}
```

`prevRoot` chains episodes so a judge can walk the history from the latest root.

## Track rules to remember

- 0G call must be **in the decision loop**, not only logging.
- Request ID per decision, episode log on 0G Storage.
- Safe-stop: brain offline → no trade, never fake decisions.
